## 反復

### 反復1(小さい実行: animal_dissection + election_day、2回、schema と no_schema、20ターン、8本)
**変更**(前回の実行から、まだ一度も回していない、3つの変更):
1. 反撃の非反復の自己点検 `Novelty`(結論より先に、最も近い過去の自分の発話と、新しい理由を申告。「新しい理由なし」なら反撃しない)。
2. 優先順位: 主張した反撃は、その場で strictly defeat の判定に使われ、争うには、反論側が次の攻撃で、その文を標的にする(受け入れを聞かない)。
3. no_schema の「すでにある論証が undercut しているか」判定は、LLM を呼ばず、常に「していない」。

**予想**(実行前):
- schema: 反撃の成功率が、前回の 7% から、50% 以上に上がる(受け入れを聞かないため)。
- schema: `no_counter`(「Repeats a reason I already used」を含む)が、1ログあたり 1 回以上出る。
- schema: 4本のうち 2本以上で、overruled の main が出る、または 20 ターンより前に終わる。
- no_schema: 反論の取り消し(`rebut_undercut_by_target`)が、ほぼ無くなる(前回 130 回/15本)。
**外れたときの読み方**: ターンが全部 20 で、Novelty による拒否が 0.5 回/ログ未満なら、Novelty は、働いていない(エージェントが、毎回「新しい理由あり」と申告している)。その場合、Novelty の中身(new_reason)を読んで、次の修正を決める。

**結果(反復1)**: schema 4本・no_schema 4本、全ログ 20 ターン。
- schema: 反撃の成功率 71%(22/31)。**予想(50% 以上)どおり**。優先順位の主張は 24 件すべてが成立のまま、**争われた件数は 0**(反論側は、主張の文を標的にした攻撃を、一度も出さない)。
- schema: `no_counter`(Repeats…)は 4 本で 1 回(0.25 回/ログ)。**予想(1 回/ログ以上)は外れ**。overruled の main は 4 本中 1 本。**予想(2 本以上)は外れ**。
- no_schema: `rebut_undercut_by_target` は 0 件。**予想どおり**。
- 後半の発話の類似度 0.6 以上は、schema で 100%(n=31)。
- 費用: $0.96。
**読み取り(1本の schema ログを、目で追った)**:
- 反論側(AG2)は、**同じ前提の攻撃を、4回、繰り返す**(turn 1, 3, 5, 8)。論文でも、反論側は繰り返してよい(Example 4.4)。
- 主張側(AG1)は、その都度、**別の角度の反撃**を出している(細かい運動技能、必須ではない、立体的な解剖学、道具と手順、解剖学的な変異)。Novelty の「新しい理由」を、自分で「あり」と判断できる。これらは、実質的には、「実物の解剖には、教育的価値がある」という、1つの根拠の言い換え・詳細化とも読める。
- 主張側が、別の角度を出せる限り、論文どおりの構造では、反論側の繰り返しに対して、主張側が詰まらず、上限まで続く(1人あたり予算 10 ターン)。
**仮説(反復2)**: 「新しい理由」の定義が緩い。立場文が与える、**別の根拠**(ground)でなければ、詳細化は新しい理由ではない、と定義すれば、主張側は、立場の根拠の数(おおよそ 3〜5)で、手が尽きる。

### 反復2(小さい実行、同じ 8本)
**変更**: 「新しい理由」を、「立場文が与える、別の根拠(または、まったく別の考慮)」と定義し、詳細化・例・より具体的な仕組み・攻撃の別の部分への向け直しは、新しい理由ではない、とした(`NoveltyCheck` の欄の説明と、反撃のプロンプト)。Novelty の申告(最も近い過去の発話の id と新しい理由)を `attempt_log`(`novelty_declared`)に残す。
**予想**(実行前):
- schema: `no_counter`(Repeats…)が、1 ログあたり 1 回以上。
- schema: 4本のうち 2本以上で、overruled の main が出る、または 20 ターンより前に終わる。
- schema: `novelty_declared` の new_reason が、立場文の根拠の名前を挙げている。
**外れたときの読み方**: `novelty_declared` の new_reason を読む。詳細化を「別の根拠」と呼んでいるなら、定義の文面を、さらに具体化する(立場文の根拠の列挙を、先に出させる)。

**結果(反復2)**: 8本のうち、1本が、モデルの出力が長すぎて失敗(反復1と同じ種類。累計 1/16)。schema 3本、no_schema 4本。
- schema: `no_counter`(Repeats…)は 3 本で 1 回(0.33 回/ログ)。**予想(1 回/ログ以上)は外れ**。overruled の main は 3 本中 1 本、20 ターンより前に終わったログは 0。**予想(2 本以上)は外れ**。
- schema: 反撃の成功率 82%(18/22)。
- no_schema: overruled の main が 12 本中 5 本(反復1は 0 本)、`no_counter` 5 回、20 ターンより前(19)に終わったログが 1 本。**no_schema では、動きが出た**(予想は schema についてのものだったので、予想としては外れ)。
- `novelty_declared` の new_reason(schema): 「新しい倫理的なトレードオフの原理」「追加性(additionality)という因果の仕組み」「有害な保存料と生物災害の廃棄物という、別の害」「AP/NGSS が解剖を必須としない」など。立場文に書かれていない、**一般知識からの、本当に新しい考慮**を、毎回、出している。
**読み取り**: 主張側の「理由の泉」は、立場文ではなく、LLM の一般知識で、事実上、尽きない。「新しい理由」の定義を、さらに厳しくしても(立場文の根拠に限る)、それは、立場文に閉じた知識になり、あなたが却下した方向になる。
**境界の規則**: 予想(止まる)が、2回続けて外れたので、**ここで止めて、報告**する。費用の累計は $1.88(上限 $70 の 3%)。
**次に考えられる方向**(未実施): (a) 予算を増やして、主張側の「理由の泉」が、どこで尽きるかを見る(30 ターン以上)。(b) 立場文の根拠に限る定義へ進む(境界に触れる。要判断)。(c) 案D(同じ質に達するまでのターン数で比べる)。
